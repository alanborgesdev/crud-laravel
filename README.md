# Sistema CRUD de Cursos - Laravel

Sistema completo de gerenciamento de cursos com Laravel e Bootstrap.

## Funcionalidades

- ✅ Listagem de cursos
- ✅ Cadastro de novos cursos
- ✅ Edição de cursos existentes
- ✅ Exclusão de cursos
- ✅ Validação de formulários
- ✅ Mensagens de feedback

## Tecnologias

- Laravel 11
- PHP 8.2+
- MySQL
- Bootstrap 5.3
- Blade Templates

## Como rodar
```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```
